# UrbanStay — Thessaloniki

Responsive boutique accommodation website for **UrbanStay**, Agias Sofias 68, Thessaloniki.

## Included
- Responsive one-page design
- English / Greek language toggle
- Full photo gallery with lightbox
- Google Maps location embed
- Click-to-email and click-to-call contact links
- License number in footer
- All supplied photos optimized to WebP

## Run locally
Open `index.html` directly, or serve the folder with any static web server.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, set the source to the `main` branch and `/ (root)`.
4. GitHub Pages will publish the site.

The project is also ready for static deployment on Vercel or Netlify.
